# Ascado - WordPress Theme (ওয়ার্ডপ্রেস থিম গাইড)

**Ascado** একটি আধুনিক, বহুমুখী ইসলামিক সোশ্যাল ওয়েলফেয়ার, হালাল মার্কেটপ্লেস, সমিতি ও ডিজিটাল এসেট ডেলিভারি ওয়ার্ডপ্রেস থিম।

---

## 🌍 সমর্থিত ভাষাসমূহ (Supported Languages)
1. **বাংলা (Bangla)** - ডিফল্ট
2. **English** - আন্তর্জাতিক ও টেকনিক্যাল
3. **العربية (Arabic)** - ফুল আরটিএল (RTL) ও ইসলামিক পরিভাষা

---

## 🚀 ওয়ার্ডপ্রেস সাইটে ইন্সটল করার নিয়ম (How to Install in WordPress)

### পদ্ধতি ১: ড্যাশবোর্ড থেকে জিপ ফাইল আপলোড (Direct ZIP Upload)
1. আপনার ওয়ার্ডপ্রেস এডমিন প্যানেলে লগইন করুন (`yourdomain.com/wp-admin`)।
2. বাম পাশের মেনু থেকে **Appearance > Themes**-এ যান।
3. উপরে থাকা **Add New Theme** বাটনে ক্লিক করে **Upload Theme** নির্বাচন করুন।
4. আমাদের অ্যাপের **"ওয়ার্ডপ্রেস থিম"** প্যানেল থেকে ডাউনলোড করা `ascado-wordpress-theme.zip` ফাইলটি সিলেক্ট করে **Install Now** চাপুন।
5. ইন্সটল শেষ হলে **Activate** বাটনে ক্লিক করুন।

### পদ্ধতি ২: cPanel / FTP ফাইল ম্যানেজার দিয়ে আপলোড
1. আপনার হোস্টিং সিপ্যানেল বা FTP-তে প্রবেশ করুন।
2. `/wp-content/themes/` ফোল্ডারে যান।
3. `ascado` নামের ফোল্ডার তৈরি করে সমস্ত ফাইল আপলোড বা এক্সট্র্যাক্ট করুন।
4. ওয়ার্ডপ্রেসের **Appearance > Themes**-এ গিয়ে **Ascado** থিমটি সক্রিয় করুন।

## 🛒 WooCommerce ও হালাল মার্কেটপ্লেস সংযোগ
- থিমটি স্বয়ংক্রিয়ভাবে WooCommerce সাপোর্ট করে।
- গ্রাহক যখন ডিজিটাল ফাইল বা পণ্য কিনবেন, লাইসেন্স কী ও ইনস্ট্যান্ট ডিজিটাল ভল্ট স্বয়ংক্রিয়ভাবে একটিভ থাকবে।
- WP REST API এর মাধ্যমে সরাসরি রিয়্যাক্ট ফ্রন্টএন্ড ও ওয়ার্ডপ্রেস ডাটাবেজ সমন্বিত থাকে।

## 🌐 ভাষা অনুবাদ ও সম্পাদনা (Loco Translate / WPML)
- থিমে `languages/ascado.pot` ফাইল যুক্ত রয়েছে।
- প্লাগিন **Loco Translate** বা **WPML** ব্যবহার করে যেকোনো নতুন শব্দ বা বাক্য বাংলা, আরবি কিংবা ইংরেজিতে নিজের মতো পরিবর্তন করতে পারবেন।
